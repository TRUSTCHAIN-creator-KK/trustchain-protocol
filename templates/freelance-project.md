# Freelance project

Use this for design, development, writing, video or similar work for one client, with a clear list of deliverables.

How to use it: fill in every [BRACKET]. Where a bracket shows choices split by a slash, keep one. Write money as numbers and dates as dates. Delete any optional clause you do not need.

## Short form

One message. Send it and keep the reply.

> Project: [DELIVERABLES SUMMARY], with [NUMBER] rounds of revisions. [TOTAL PRICE] [CURRENCY], [DEPOSIT AMOUNT] up front, the rest on delivery. New items or extra rounds get quoted first. Delivery [DELIVERY DATE], as long as feedback comes back within [NUMBER] days. If we stop early, you pay for the work done so far. Reply yes if that's the deal.

## Full form

- **Client:** [CLIENT NAME], [COMPANY IF ANY], [CLIENT EMAIL]
- **Freelancer:** [FREELANCER NAME], [BUSINESS NAME IF ANY], [FREELANCER EMAIL]
- **Date agreed:** [DATE AGREED]

### 1. What we're doing

Deliverables, one by one: [DELIVERABLES LIST]. Format: [FILE FORMATS]. Source files: [INCLUDED / NOT INCLUDED / INCLUDED FOR AMOUNT]. Revision rounds included: [NUMBER]. Done means [WHAT DONE LOOKS LIKE], confirmed by [WHO CONFIRMS]. Not included: [EXCLUDED ITEMS].

### 2. Price and payment

[TOTAL PRICE] [CURRENCY]. [DEPOSIT AMOUNT] before work starts, [MILESTONE PAYMENTS], and the balance on delivery. Invoices are due within [NUMBER] days. If a payment is more than [NUMBER] days late, work pauses until it arrives, and the dates move by the same number of days.

### 3. Changes

New items or extra revision rounds are quoted in writing. They start after you confirm. Extra rounds are [PRICE PER ROUND] each. Other extra work is [HOURLY RATE] per hour. Each change is its own written note. This text is not edited.

### 4. Dates

Start [START DATE]. Milestones: [MILESTONE DATES]. Delivery [DELIVERY DATE]. Feedback comes back within [NUMBER] days of each draft. If feedback or materials from you arrive late, delivery moves by the same number of days.

### 5. If someone walks

If either of us ends the project early, you pay for work completed up to that date. The deposit [IS KEPT / COUNTS TOWARD THE WORK DONE / IS REFUNDED, MINUS WORK DONE]. Once that is paid, I hand over [WHAT IS HANDED OVER].

### Agreed

- [CLIENT NAME], [DATE]
- [FREELANCER NAME], [DATE]

Each of us keeps a copy.

## Optional clauses

Add any that fit, above "Agreed". Each one stands alone.

- **Paid first round.** A first concept round is [PRICE]: [WHAT IT INCLUDES]. If we go ahead, it comes off the project price.
- **Hourly with clear edges.** [HOURLY RATE] per hour. Calls and admin [ARE / ARE NOT] counted. I send the hours every [WEEK / TWO WEEKS], so the total is never a surprise.
- **Who does the work.** [COLLABORATOR] handles [TASKS]. Same price, and I review that work before you see it.
- **One channel for approvals.** Approvals and changes go through [EMAIL / CHAT / PROJECT TOOL], in writing.
- **Use of the work.** After full payment, you may use the work for [USES]. [ANY LIMITS].
- **Portfolio.** I may show the finished work in my portfolio [ANY LIMITS, FOR EXAMPLE AFTER LAUNCH].
- **File storage.** I keep project files for [HOW LONG] after delivery.

## Example

> Project: a logo and a one-page brand guide, with 2 rounds of revisions. $1,800 USD, $600 up front, the rest on delivery. New items or extra rounds get quoted first. Delivery March 20, as long as feedback comes back within 3 days. If we stop early, you pay for the work done so far. Reply yes if that's the deal.

A paid first round could read: "A first concept round is $300: two directions and one call. If we go ahead, it comes off the project price."

## Check the rules where you live

Who owns the work, how cross-border payments are taxed, and whether late fees are allowed can differ by place. Get local advice first if the project involves exclusive ownership of the work, a non-compete or exclusivity clause, a client in another country, a long standard contract from a company with its own legal team, or more money than you could afford to lose. This template does not say what the law is anywhere.
